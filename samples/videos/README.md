# Sample videos

Record 3 short (≤30 s) screen recordings of real broken flows and drop them here as `.mp4`. Videos are gitignored — only this README is committed.

Suggested targets:
1. Public demo app with a known-broken checkout (or a local Vite app with a bug you plant on purpose).
2. Form-validation edge case (empty required field, bad email, etc.).
3. Race condition / stale UI state (double click, back-button after delete, etc.).

Naming: `bug_<slug>.mp4` e.g. `bug_checkout_500.mp4`.
